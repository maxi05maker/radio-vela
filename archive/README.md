# Nachrichten- & Wetter-Archiv

Dieses Verzeichnis hält dauerhaft fest, wann bei Radio Vela die Sendung **„Nachrichten & Wetter“** tatsächlich laut laut.fm gestartet wurde.

## Zeitraum

10.08.2026, 22:00 Uhr bis 16.08.2026, 23:59 Uhr (Europe/Berlin).

## Datenquelle

Die tatsächliche Startzeit kommt aus der öffentlichen laut.fm-Playlist-Historie. Es wird keine Uhrzeit geschätzt oder erfunden.

Die Daten liegen in `news-and-weather.json` und werden über die Archivseite angezeigt.
